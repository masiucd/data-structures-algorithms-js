# Most frequent item count

## Description

Given an array of integers, return the number of times the most frequent element appears.

## Examples

```js
mostFrequentItemCount([1, 2, 3, 1, 2, 1]); // 3
mostFrequentItemCount([1, 2, 3, 4]); // 1
mostFrequentItemCount([1, 2, 3, 4, 5]); // 1
```

## Constraints

- The array can be empty.
- The array will only contain integers.
- The array will only contain positive integers.

## Note

- If there are multiple elements with the same frequency, return the count of the first one.
- The array can be empty.
- The array will only contain integers.
- The array will only contain positive integers.
